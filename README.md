# izily-macro-data

Flux JSON public utilisé par le Thermomètre de Marché d'IZILY FIRE.

- `macro.json` : CAPE Shiller (S&P 500) et PER forward Europe, mis à jour chaque jour.
- Adresse du flux : https://raw.githubusercontent.com/izilybourse/izily-macro-data/main/macro.json

Format : `{"date":"AAAA-MM-JJ","cape":40.5,"capeAvg":27.5,"peEu":14.2,"peEuAvg":14.5}`
